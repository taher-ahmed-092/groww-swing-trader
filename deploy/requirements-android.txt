# Cosmic Punk — Android dependency list (for a glibc ARM64 environment).

# IMPORTANT: this is for a glibc aarch64 environment — i.e. a proot-distro Ubuntu
# container inside Termux (see TERMUX_GUIDE.md), NOT native Termux.
#
# Why: the mandatory Rust/C dependencies (pydantic-core, jiter, uuid-utils, orjson,
# ormsgpack, greenlet, pynacl, httptools, ...) publish ONLY glibc manylinux_aarch64
# wheels and have no android-tagged wheels. In a glibc env they install with ZERO
# compilation. Native Termux (Bionic libc) rejects those wheels and tries to build
# from source, which needs a Rust toolchain and still fails for uuid-utils on the
# aarch64-android target. proot-distro gives you glibc, so everything just works.
#
# Inside proot Ubuntu you can simply `uv sync` (recommended). This file is the
# pip-only alternative:  pip install -r deploy/requirements-android.txt
#
# Excluded optional extras (heavy / compiled; the system runs fully without them):
#   xgboost      -> signal combiner; only after 30+ trades.  Laptop: uv sync --extra ml
#   transformers -> local FinBERT;   keyword fallback otherwise. Laptop: uv sync --extra nlp
